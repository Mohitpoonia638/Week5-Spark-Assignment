# Week 5 - Apache Spark Assignment

## Objective

Understand Spark fundamentals and perform data cleaning, transformation, and aggregation using Apache Spark DataFrames.

## Dataset

A sample sales and transaction dataset containing:

* User Information
* Transaction Details
* Sales Data
* Region Information
* Store Information

## Tasks Performed

1. Studied limitations of MapReduce
2. Explained Spark In-Memory Computing
3. Removed duplicate records
4. Applied filtering conditions
5. Performed aggregations using groupBy
6. Handled missing values using na.drop() and na.fill()
7. Modified schema and data types
8. Explained DataFrame immutability
9. Built a complete Spark data processing pipeline
10. Generated insights from transformed data

## Tools Used

* Python
* PySpark
* Apache Spark
* Jupyter Notebook

## Learning Outcomes

* Spark DataFrame Operations
* Data Cleaning and Transformation
* Aggregation Functions
* Schema Management
* Handling Missing Values
* Distributed Data Processing

This assignment demonstrated the use of Apache Spark for data cleaning, transformation, aggregation, schema handling, and pipeline creation. Spark's distributed and in-memory processing capabilities make it an efficient framework for large-scale data analytics.
